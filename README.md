# Easy Dashboard

Replace the WordPress dashboard with a clean welcome page: large tiles, a branded header and faster access to your content.

[![WordPress plugin](https://img.shields.io/wordpress/plugin/v/easy-dashboard.svg)](https://wordpress.org/plugins/easy-dashboard/)
[![Active Installs](https://img.shields.io/wordpress/plugin/installs/easy-dashboard.svg)](https://wordpress.org/plugins/easy-dashboard/)
[![Downloads](https://img.shields.io/wordpress/plugin/dt/easy-dashboard.svg)](https://wordpress.org/plugins/easy-dashboard/)

Widgets and clutter give way to a screen that shows each user only the sections they can actually reach — useful for clients, editors and sites with custom post types.

## Features

- Replaces the default Dashboard with a custom welcome page
- Large tiles for posts, pages, media, custom post types and admin sections
- Tiles follow the current user's capabilities, and reuse the translated WordPress menu labels
- Quick actions on content tiles: open the list view or create new content
- Branded header with site logo, greeting and optional tagline
- Admin-only settings panel, inline on the welcome page
- Preset colour schemes or a custom two-colour gradient, with live preview
- Pending updates notice for administrators
- Button to open the WordPress command palette (WordPress 6.9+)
- One tile always leads back to the classic dashboard

## Requirements

- WordPress 6.0+
- PHP 7.4+

## Install

From the WordPress admin: **Plugins → Add New → search "Easy Dashboard"**.

Open any admin page afterwards: the Dashboard screen redirects to Easy Dashboard. Administrators can set the tagline and colours from the gear icon in the header.
